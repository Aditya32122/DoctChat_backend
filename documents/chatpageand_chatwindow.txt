Relationship Between Components
Parent-Child Relationship:

ChatPage is the parent component that manages state and data flow
ChatPage passes data and functions to ChatWindow through props
Data Flow:

User messages flow from MessageInput to ChatPage to API
API responses flow from ChatPage to ChatWindow for display
Chat history is loaded from Firebase/localStorage by ChatPage and passed to ChatWindow
Functionality Division:

ChatPage: Handles data, API calls, and state management
ChatWindow: Focuses on displaying messages and user interface elements
State Management:

ChatPage maintains the primary state (messages, loading, authentication)
